Cliquez ici pour consulter les instructions de cette interface de recherche
1. Utilisez l'une des méthodes ci-dessous pour définir votre recherche géographique :
 a. Entrez une adresse et appuyez sur Localiser pour la localiser, ou
 b. Appuyez sur le bouton Sélectionner une zone et cliquez pour sélectionner deux coins opposés, ou
 c. Appuyez sur le bouton Sélectionner un point et cliquez pour sélectionner un seul point
2. Appuyez sur le bouton Rechercher pour voir les résultats                         ( plus d'aide )
