Términos Definidos

JERARQUÍA DE COLECCIONES

Las colecciones se organizan por Grupos de Colecciones, que contienen Colecciones, y las Colecciones contienen Subcolecciones. Esta organización jerárquica permite búsquedas y exploraciones generales a nivel del Grupo de Colecciones, así como búsquedas más específicas a nivel de la Colección, para una usabilidad óptima según las diversas necesidades de los usuarios.

Al leer las estadísticas por Colección, las vistas y búsquedas realizadas desde la página principal y las páginas de Grupos de Colecciones no se encuentran dentro de las colecciones y, por lo tanto, no se incluyen en las estadísticas de la Colección.

GRUPOS DE COLECCIONES

Los grupos de colecciones son agrupaciones de colecciones dentro de esta biblioteca. Los Grupos de Colecciones simplifican la búsqueda en múltiples Colecciones simultáneamente. Los Grupos de Colecciones también conectan materiales menos relacionados entre sí para aumentar la probabilidad de hallazgos fortuitos, donde los usuarios que buscan un tema pueden encontrar fácilmente algo relacionado y de gran utilidad que no habían considerado. Por ello, los Grupos de Colecciones generalmente se construyen por temática.

Como agregado, las vistas a nivel del Grupo de Colecciones no cuentan para ninguna Colección en particular y no se incluyen en las estadísticas basadas en Colecciones.

COLECCIONES

Las colecciones son el principal método para definir y agrupar materiales relacionados, y son las estructuras jerárquicas más familiares para especialistas en la materia, socios y otros usuarios internos. Una sola Colección puede existir en varios Grupos de Colecciones, y una sola Colección puede tener muchas subcolecciones.

Un elemento puede pertenecer a varias Colecciones, pero siempre se selecciona una Colección como principal, de modo que todas las vistas del elemento se registren dentro de una sola Colección.

SUBCOLECCIONES

La unidad agrupada más pequeña es la Subcolección. Un solo elemento puede pertenecer a varias Subcolecciones dentro de la misma colección, o a varias Colecciones y a Subcolecciones dentro de cada Colección.

Dado que todos los elementos de las Subcolecciones tendrán una Colección principal, las estadísticas de uso de las Subcolecciones también se incluyen en las estadísticas de uso de la Colección.

VISTAS

Las vistas son los accesos reales a las páginas. Cada vez que una persona visita {0}, se cuenta como una vista. Las estadísticas de {0} se depuran para que se eliminen las vistas provenientes de robots, que los motores de búsqueda utilizan para indexar sitios web. Si no se eliminaran, las vistas en todas las colecciones y elementos serían mucho más altas. Las estadísticas de uso web siempre son algo falibles, y esta es una de las formas de garantizar estadísticas de uso de mejor calidad.

Algunas estadísticas web cuentan las "descargas de elementos de página" como vistas, lo cual es muy inexacto porque cada página tiene múltiples elementos. Por ejemplo, la página principal de la biblioteca digital, {0}, incluye el HTML de la página y todas las imágenes. Si las estadísticas contaran cada "descarga de elemento de página" como un acceso, cada visita a la página principal se contaría como más de 30 "descargas de elementos de página". Para complicar aún más las cosas, algunos repositorios digitales solo ofrecen descargas en PDF para que los usuarios vean los elementos. Esos repositorios digitales registran "descargas de elementos", que son las más equivalentes a nuestras estadísticas de uso por "elemento".

VISITAS

Cada vez que una persona visita esta biblioteca digital, se cuenta como una vista, pero eso significa que un mismo usuario que visita el sitio repetidamente puede registrar un gran número de vistas. Las visitas ofrecen una mejor estadística de cuántos usuarios "únicos" diferentes están utilizando el sitio. Las visitas incluyen todas las vistas provenientes de una misma dirección IP (la dirección web del ordenador del usuario al conectarse) registradas en el archivo de registro web dentro de una hora.

Esta también es una estadística falible, ya que las direcciones IP de los usuarios se reutilizan con frecuencia en las redes. Conectarse a una red inalámbrica gratuita significa que esa red asigna una dirección IP a su ordenador, y luego, cuando se desconecta, esa dirección IP se asignará al siguiente usuario que la necesite. Para un recurso basado en un campus con tantos usuarios que se conectan a través de la VPN o desde el campus, el margen de error aumenta en las estadísticas basadas en visitas.

PÁGINAS PRINCIPALES

Para cada uno de los elementos de la Jerarquía de Colecciones, las páginas principales son las páginas de inicio o de aterrizaje, las páginas de búsqueda, las páginas de contacto y cualquier otra página complementaria.

Cuando los usuarios realizan una búsqueda a través de las páginas de la Colección y ven los resultados, esas páginas de resultados de búsqueda también se incluyen en las páginas principales. Una vez que un usuario hace clic en uno de los elementos de los resultados de búsqueda, ese elemento deja de ser una de las páginas principales. Las vistas de resultados de búsqueda en los modos de miniatura, tabla y breve se incluyen todas en las páginas principales de la Colección.

EXPLORACIONES

Las exploraciones incluyen vistas contra exploraciones estándar, como Todos los Elementos y Elementos Nuevos (cuando están disponibles). También incluyen todas las vistas de exploraciones no estándar.

RESULTADOS DE BÚSQUEDA

Las vistas de resultados de búsqueda incluyen cada vista de una sección de resultados de búsqueda, incluyendo las búsquedas que no arrojaron resultados.

TÍTULOS Y ELEMENTOS

Los títulos corresponden a unidades bibliográficas individuales, como un libro o un periódico. Los elementos son los volúmenes dentro de los títulos. Así, un libro puede tener un título y un elemento, mientras que un periódico puede tener un título y miles de elementos.

Los títulos con un solo elemento (o volumen) resultan funcionalmente equivalentes para los usuarios. Sin embargo, para elementos como los periódicos, un solo título puede corresponder a miles de elementos.

Los lectores de la documentación técnica y los usuarios internos identifican los títulos por su identificador bibliográfico (BIBID) y los elementos dentro de cada título por el BIBID más el identificador de volumen (VID).

VISTAS DE TÍTULOS

Las vistas de títulos incluyen todas las vistas a nivel de título.

VISTAS DE ELEMENTOS

Las vistas de elementos incluyen únicamente las vistas a nivel de elemento.

VISTAS DE CITA

Para cada elemento, la vista predeterminada se establece en el elemento de página (ampliable o estática, según la selección del usuario y la disponibilidad de cada una de las vistas para ese elemento). Todos los elementos también incluyen una "Vista de Cita" que no se selecciona de forma predeterminada. Las "Vistas de Cita" cuentan el número de veces que un usuario elige la "Vista de Cita" para un elemento.

BÚSQUEDAS DE TEXTO

Las búsquedas de texto son búsquedas a nivel de elemento dentro del texto de un solo documento. Estas devuelven las páginas en las que aparece el término o los términos buscados.

VISTAS ESTÁTICAS

Para cada elemento de esta biblioteca, se genera una página estática para que los motores de búsqueda la indexen. Cuando un elemento aparece en los resultados de un motor de búsqueda estándar, el enlace redirige al usuario a la página estática. Cualquier navegación adicional lleva al usuario a las páginas generadas dinámicamente dentro de esta biblioteca. Se han hecho esfuerzos para eliminar de estas cifras todas las vistas provenientes de la indexación de motores de búsqueda. Estas cifras representan el número de usuarios que ingresaron a esta biblioteca desde un motor de búsqueda.
