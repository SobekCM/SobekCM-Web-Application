Termos Definidos

HIERARQUIA DE COLEÇÕES

As coleções são organizadas por Grupos de Coleções, que contêm Coleções, e as Coleções contêm Subcoleções. Essa organização hierárquica permite pesquisas e navegações gerais no nível do Grupo de Coleções e pesquisas mais detalhadas no nível da Coleção, para uma usabilidade ideal conforme as diversas necessidades dos usuários.

Ao ler as estatísticas por Coleção, as visualizações e pesquisas feitas a partir da página principal e das páginas de Grupos de Coleções não estão dentro das coleções e, portanto, não são incluídas nas estatísticas da Coleção.

GRUPOS DE COLEÇÕES

Grupos de coleções são agregações de coleções nesta biblioteca. Os Grupos de Coleções simplificam a pesquisa em várias Coleções simultaneamente. Os Grupos de Coleções também conectam materiais menos relacionados entre si, aumentando a probabilidade de descobertas fortuitas, em que usuários pesquisando um tópico podem facilmente encontrar algo relacionado e criticamente útil que não haviam considerado. Assim, os Grupos de Coleções geralmente são construídos por tema.

Como um agregado, as visualizações no nível do Grupo de Coleções não contam para nenhuma Coleção específica e não são incluídas nas estatísticas baseadas em Coleções.

COLEÇÕES

As coleções são o principal método para definir e reunir materiais relacionados e são as estruturas hierárquicas mais familiares para especialistas na área, parceiros e outros usuários internos. Uma única Coleção pode existir em vários Grupos de Coleções, e uma única Coleção pode ter muitas subcoleções.

Um item pode estar em várias Coleções, mas uma Coleção é sempre selecionada como principal, de modo que todas as visualizações do item estarão dentro de uma única Coleção.

SUBCOLEÇÕES

A menor unidade reunida é a Subcoleção. Um único item pode pertencer a várias Subcoleções dentro da mesma coleção, ou a várias Coleções e a Subcoleções dentro de cada Coleção.

Como todos os itens de Subcoleções terão uma Coleção principal, as estatísticas de uso das Subcoleções também são incluídas nas estatísticas de uso da Coleção.

VISUALIZAÇÕES

As visualizações são os acessos reais às páginas. Cada vez que uma pessoa acessa {0}, isso conta como uma visualização. As estatísticas de {0} são depuradas para que as visualizações provenientes de robôs, usados pelos mecanismos de pesquisa para indexar sites, sejam removidas. Se não fossem removidas, as visualizações em todas as coleções e itens seriam muito mais altas. As estatísticas de uso da web são sempre um tanto falíveis, e esta é uma das formas de garantir estatísticas de uso de melhor qualidade.

Algumas estatísticas da web contam "downloads de itens de página" como visualizações, o que é altamente impreciso, pois cada página possui vários itens. Por exemplo, a página principal da biblioteca digital, {0}, inclui o HTML da página e todas as imagens. Se as estatísticas contassem cada "download de item de página" como um acesso, cada visualização única da página principal seria contada como mais de 30 "downloads de itens de página". Para complicar ainda mais, alguns repositórios digitais oferecem apenas downloads em PDF para que os usuários visualizem itens. Esses repositórios digitais registram "downloads de itens", que são os mais equivalentes às nossas estatísticas de uso por "item".

VISITAS

Cada vez que uma pessoa acessa esta biblioteca digital, isso conta como uma visualização, mas isso significa que um único usuário que acessa o site repetidamente pode registrar um grande número de visualizações. As visitas oferecem uma estatística melhor de quantos usuários "únicos" diferentes estão usando o site. As visitas incluem todas as visualizações a partir de um determinado endereço IP (o endereço web do computador do usuário no momento da conexão), conforme registrado no arquivo de log da web dentro de uma hora.

Esta também é uma estatística falível, já que os endereços IP dos usuários são frequentemente reutilizados nas redes. Conectar-se a uma rede sem fio gratuita significa que essa rede atribui um endereço IP ao seu computador e, quando você se desconecta, esse endereço IP será atribuído ao próximo usuário que precisar dele. Para um recurso baseado em campus com tantos usuários conectando-se via VPN ou a partir do campus, a margem de erro aumenta para estatísticas baseadas em visitas.

PÁGINAS PRINCIPAIS

Para cada um dos elementos na Hierarquia de Coleções, as páginas principais são as páginas iniciais ou de destino, as páginas de pesquisa, as páginas de contato e quaisquer outras páginas complementares.

Quando os usuários realizam uma pesquisa através das páginas da Coleção e visualizam os resultados, essas páginas de resultados de pesquisa também são incluídas nas páginas principais. Assim que um usuário clica em um dos itens nos resultados da pesquisa, esse item deixa de ser uma das páginas principais. As visualizações de resultados de pesquisa nos modos miniatura, tabela e resumido estão todas incluídas nas páginas principais da Coleção.

NAVEGAÇÕES

As navegações incluem visualizações em relação às navegações padrão, como Todos os Itens e Novos Itens (quando disponíveis). Também incluem todas as visualizações de navegações não padrão.

RESULTADOS DE PESQUISA

As visualizações de resultados de pesquisa incluem cada visualização de uma seção de resultados de pesquisa, incluindo pesquisas que não retornaram resultados.

TÍTULOS E ITENS

Os títulos correspondem a unidades bibliográficas individuais, como um livro ou um jornal. Os itens são os volumes dentro dos títulos. Assim, um livro pode ter um título e um item, enquanto um jornal pode ter um título e milhares de itens.

Títulos com apenas um item (ou volume) parecem funcionalmente equivalentes para os usuários. No entanto, para itens como jornais, um único título pode corresponder a milhares de itens.

Os leitores da documentação técnica e os usuários internos identificam títulos por seu identificador bibliográfico (BIBID) e itens dentro de cada título pelo BIBID mais o identificador de volume (VID).

VISUALIZAÇÕES DE TÍTULOS

As visualizações de títulos incluem todas as visualizações no nível do título.

VISUALIZAÇÕES DE ITENS

As visualizações de itens incluem apenas visualizações no nível do item.

VISUALIZAÇÕES DE CITAÇÃO

Para cada item, a visualização padrão é definida como o item de página (ampliável ou estático, com base na seleção do usuário e na disponibilidade de cada uma das visualizações para aquele item). Todos os itens também incluem uma "Visualização de Citação", que não é selecionada por padrão. As "Visualizações de Citação" contam o número de vezes que um usuário escolhe a "Visualização de Citação" para um item.

PESQUISAS DE TEXTO

As pesquisas de texto são pesquisas no nível do item, dentro do texto de um único documento. Elas retornam as páginas em que o termo ou os termos aparecem.

VISUALIZAÇÕES ESTÁTICAS

Para cada item nesta biblioteca, uma página estática é gerada para que os mecanismos de pesquisa a indexem. Quando um item aparece nos resultados de um mecanismo de pesquisa padrão, o link encaminha o usuário para a página estática. Qualquer navegação adicional leva o usuário para as páginas geradas dinamicamente dentro desta biblioteca. Foram feitos esforços para remover desses números todas as visualizações provenientes da indexação por mecanismos de pesquisa. Esses números representam o número de usuários que entraram nesta biblioteca a partir de um mecanismo de pesquisa.
