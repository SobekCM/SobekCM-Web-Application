Clique aqui para ver as instruções desta interface de pesquisa
1. Use um dos métodos abaixo para definir sua pesquisa geográfica:
 a. Digite um endereço e pressione Localizar Endereço para localizá-lo, ou
 b. Pressione o botão Selecionar Área e clique para selecionar dois cantos opostos, ou
 c. Pressione o botão Selecionar Ponto e clique para selecionar um único ponto
2. Pressione o botão Pesquisar para ver os resultados                         ( mais ajuda )
